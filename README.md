# Data Visualization and Analytics Portfolio

A professional, high-performance personal portfolio designed for the Data Visualization and Analytics (DVA) field. This project utilizes a modern bento-box grid layout with advanced glassmorphism and data-centric aesthetics.

## Overview

This portfolio showcases the technical expertise and project work of Parthraj Singh Bhati. It is engineered to provide a seamless user experience while highlighting core capabilities in exploratory data analysis, business intelligence, and full-stack development.

## Technical Stack

- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Design System:** Custom Obsidian Bento System
- **Styling:** Vanilla CSS with advanced backdrop-filters and mesh gradients
- **Typography:** Plus Jakarta Sans, Manrope, and Space Grotesk

## Key Features

- **Responsive Bento Grid:** A modular layout that adapts to various screen sizes while maintaining visual hierarchy.
- **Advanced Glassmorphism:** Multi-layered background blurs and border-beam lighting effects for a premium digital feel.
- **Project Case Studies:** Interactive cards linking to specialized repositories for FoodHub Analysis and HR Analytics.
- **Performance Optimized:** Minimal dependencies and efficient CSS-driven animations for fast load times.

## Getting Started

To run this project locally, follow these steps:

### Prerequisites

- Node.js (v18.0 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/parthrajsinghbhati/DVA-Portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd DVA-Portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

### Production

Build the application for production:
```bash
npm run build
```

## Project Structure

- `src/App.jsx`: Core application logic and bento structure.
- `src/index.css`: Global design tokens, mesh gradients, and glassmorphic utilities.
- `public/`: Static assets and icons.
